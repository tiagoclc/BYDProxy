Proxy para compartilhar a internet via hotspot do BYD Dolphin (e outros com dilink 3. Não testei em outros carros com dilink 4 e 5).

Instruções:

Basta instalar o apk na multimídia e liberar a inicialização automática.

Instale, também, o app do celular, se quiser usar whatsapp, telegram, youtube etc. no celular.

Se quiser apenas navegar em páginas web, siga as instruções abaixo:

Quando conectar o celular ou outro dispositivo ao hotspot, deve ir nas configurações da rede, no aparelho que conectou, para inserir o proxy.

Deve escolher a opção de proxy automático e definir o seguinte endereço:
http://192.168.43.1:8880/proxy.pac 

(o ip deve ser o mesmo do hotspot 192.168.43.1 é o ip padrão do hotspot do byd dolphin. Talvez seu carro tenha outro endereço).
